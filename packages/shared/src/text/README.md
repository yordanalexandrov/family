# text

## Overview

Малки чисти помощни функции за текст, които api и web ползват еднакво. Без зависимости извън езика.

## Interface

- `hint.ts:withHint` — връща етикета, последван от ` · „подсказка“`, или само етикета, когато няма подсказка.
- `lines.ts:nonEmptyLines` — разделя текст на редове, подрязва всеки ред и маха празните.

## Invariants

- `hint.ts:withHint` — всяка празна стойност (`null`, `undefined`, `''`) връща етикета непроменен; съкращаването на подсказката е работа на извикващия, не на функцията.
- `lines.ts:nonEmptyLines` — пази реда на редовете; разделя само по `\n`, а `\r` изчезва при подрязването.

## Side Effects

- None.
