# Всеки AI контракт се изпълнява от отделен изолиран OpenClaw агент

API-то не ползва личния агент на Дако в OpenClaw. За всеки контракт (`menu.propose`, `recipe.suggest`) се създава отделен OpenClaw агент със собствен workspace, фиксиран prompt с JSON schema на изхода и минимални права (търсене в интернет за рецепти; без файлове, exec и чат канали). API-то валидира отговора със Zod schema от `packages/shared` и повтаря веднъж при невалиден изход. Така prompt-ът, правата и разходът на всеки контракт са изолирани и подменяеми поотделно, за сметка на малко повече конфигурация на сървъра.
