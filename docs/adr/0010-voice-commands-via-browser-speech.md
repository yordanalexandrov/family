# Гласовите команди в Готвене минават през разпознаването на браузъра, при поискване

В Готвене ръцете са мокри, затова стъпките се сменят и с глас (#224). Ползваме `SpeechRecognition` от Web Speech API на браузъра (Chrome на таблета и телефона, `bg-BG`). Chrome праща звука към услугата на Google, докато слушането е включено. Затова слушането се пуска само с докосване в Готвене, вижда се през цялото време и спира при излизане. Няма ключова дума, която да чака винаги. Разпознатият текст не стига до api и не се пази никъде. Командите са няколко фиксирани думи, а по-дълга фраза се пренебрегва, за да не сменя стъпката разговорът в кухнята.

Четенето на глас (`speechSynthesis`) ползва гласа на системата (Google Speech Services на Android) и работи без мрежа, ако българският глас е свален. Слушането иска мрежа, докато рецептите под ръка я нямат. Без мрежа Готвене работи както преди, само без слушане.

## Considered Options

- Модел на устройството (Vosk или Whisper в WASM): без звук към Google и без мрежа, но тежък за евтин таблет, а за български има малко готови модели. `processLocally` на Web Speech API още не е сигурно наличен на Android. Може да замени облачното разпознаване по-късно, без да сменя командите.
- Винаги слушащ микрофон с ключова дума: удобно, но микрофонът в кухнята пращаше звук навън по цял ден, а за български няма готова ключова дума в браузъра.
- Само четене на глас, без команди: не решава мокрите ръце при „напред“.
