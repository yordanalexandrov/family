# Google Calendar се чете със service account, не с OAuth на потребител

Платформата само чете семейните календари. Избираме Google Cloud service account, с когото календарите се споделят с право „виж“, вместо OAuth consent на семейния акаунт: без refresh логика, без изтичащи на 7 дни токени в „testing“ режим и без публикуване на OAuth приложение. Цената е еднократна ръчна стъпка (създаване на SA и споделяне на всеки календар) и това, че SA вижда само изрично споделените календари.
